# 规则表格式（Excel）

脚本是**数据驱动**的：装备「该不该刷」完全由 Excel 规则表决定，脚本只负责读表 + 校验 + 执行。
解析逻辑在 `darkzone/rules.py`（`parse_sheet()` / `RuleBlock.validate()`）。

## Sheet 布局

| 列 | 表头行 | 数据行 |
|---|---|---|
| A | 类别（如「暗区首领」） | 限定条件（如「除了阿贾克斯和雷诺伊尔」） |
| B | 触发时机（如「验证完暗区首领后」） | 空（或说明文字） |
| C、D、E… | 装备池表头（含「装备选择 / 装备池 / 选项 / 装备」字样） | 该槽位的可选装备名 |

约定：

- **列 B 往右的第一个池表头行 = 一个规则块的开始**。A 列写类别、B 列写时机，C/D/E… 各列对应详情页
  「第一行 / 第二行 / 第三行」装备槽位（从左到右）。
- **同一表头行下面的连续数据行，都属于这一个规则块**，直到再次出现新的表头行。
- **数据行 A 列**是限定条件/排除名单，例如「除了阿贾克斯和雷诺伊尔」→ 若当前首领是这两个名字之一，
  该规则块不适用（`RuleBlock.excluded`）。空就是无排除。
- **每个数据行的 C/D/E 列**是该槽位的候选装备，一格一件。同一槽位（同一列）纵向上累积成一个池子。

## 校验语义（重要）

- **一个槽位 = 一个池子**，详情页第 N 行装备只需要落在它自己那一列的池子里即算「在池内」。
- **各档独立判定，行号之间没有对应关系**：不存在「第一行选了 C3 就必须配 D3/E3」这种组合约束。
  C 列里任何一件、D 列里任何一件、E 列里任何一件，各自命中即可。

## 真实样例（对应内置 `rules_sample.xlsx`）

| A | B | C | D | E |
|---|---|---|---|---|
| 暗区首领 | 验证完暗区首领后 | 第一行装备选择 | 第二行装备选择 | 第三行装备选择 |
| 除了阿贾克斯和雷诺伊尔 | | AUG突击步枪 | BT101战术防弹衣 | 钢铁新星战术头盔 |
| | | SJ16栓动步枪 | 治安官重型防弹衣 | 野战登山背包 |
| | | AR30栓动步枪 | KN复合防弹衣 | RAL重型军用背包 |
| | | A545突击步枪 | AL指挥官弹挂甲 | |
| | | MK14射手步枪 | | |

解读 = **1 个规则块**，排除名单 `[阿贾克斯, 雷诺伊尔]`，三个槽位：

- 槽1（第一行）池 = {AUG突击步枪, SJ16栓动步枪, AR30栓动步枪, A545突击步枪, MK14射手步枪}
- 槽2（第二行）池 = {BT101战术防弹衣, 治安官重型防弹衣, KN复合防弹衣, AL指挥官弹挂甲}
- 槽3（第三行）池 = {钢铁新星战术头盔, 野战登山背包, RAL重型军用背包}

## 怎么改规则

- 用 Excel 打开 `rules_sample.xlsx` 直接增删行/列（保持结构：A=类别/排除、B=时机、C+=池）。
- 或改 `scripts/make_sample_rules.py` 里的数据再重新生成：`python scripts/make_sample_rules.py`。
- **跑之前用离线预演**先验一下规则表被正确解析（`--image` 给任意一张 3200x1440 横屏截图）：
  `python -m darkzone.runner --image <你的截图.png> --device 3200x1440 --rules <你的表.xlsx>`
  —— 它会把每个槽位读到的装备、对应池子、in_pool 判定都打印出来，一眼看出解析对不对。

## 标题列识别容差

- 池表头使用宽松正则 `(装备选择|装备池|选项|装备)`，所以写成「第一行装备」/「装备1」/「选项A」都能认。
- 槽位号从表头里抽（正则 `第\s*([一二三四五六七八九十\d]+)\s*[行档个]`），从 1 开始编号。
- 详情页槽位由 `darkzone/reader.py` 按 OCR 行位置（上下排列）归属，与表里的 C/D/E 列一一对应。
  解析出的行数 ≠ 槽位数时脚本会重读，仍不对就报 `row_count_unexpected` 停手，不猜着点。
